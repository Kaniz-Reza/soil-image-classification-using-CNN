# Dataset

The datasets used in this project are not included directly in this repository
because of their size.

The project uses two Kaggle soil-image datasets:
- **Dataset 1**: 1,550+ images across four soil types - alluvial, black, clay, and red soil.
- **Dataset 2**: 4,200+ images across five soil types - black, cinder, laterite, peat, and yellow soil.

Please refer to the research report (`report/soil-classification-report.pdf`) and the
notebooks in `notebooks/` for full dataset details, preprocessing, and experimental setup.
